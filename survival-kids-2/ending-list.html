『サバイバルキッズ2 脱出!!双子島』のエンディング条件をまとめたページです。

エンディング1：灯台から脱出

必要アイテム

  • でんきゅう（灯台・地下1階）
  • はりがね（灯台5階「こわれたモーター」を分解）
  • モーター（旧軍施設・ダクト）
  • かんきせん（旧軍施設・ダクト）

灯台地下1階の鍵付き扉

パスワードは、リモ島「やまの　うらがわ」西側にある小屋のノートに記載されています。一度読むと、灯台地下1階の扉で入力できるようになります。

手順

  1. 灯台6階（最上階）で「でんきゅう」を使用する。
  2. 灯台5階の「こわれたモーター」を取り外し、「モーター」を取り付ける。
  3. 灯台地下1階の水力発電機左側の壁を調べ、「電気のコードが切れているみたい」と出る場所で「はりがね」を使用する。
  4. 水力発電機に「かんきせん」を取り付ける。

※水力発電機に先に「かんきせん」を付けている場合、いったん「かんきせん」を外す必要があります。

発生タイミング

灯台の復旧後、約4日ほど経つと船の霧笛が聞こえます。灯台から外に出る、または「とうだい みさき」の灯台の場所へ行くと船が来てエンディング1に入ります。

別のエンディングも狙う場合は、灯台復旧後は別のエリアで過ごすと安全です。船が到着時に灯台内にいると、外に出た時にそのままエンディング1に入ってしまいます。

エンディング2：ボートで脱出

必要アイテム

  • でんきゅう（灯台・地下1階）
  • でんち（旧軍施設・地下1階のゴミ箱から入手できる「めざましどけい」を分解）
  • ドラムかん（旧軍施設 or 軍艦）
  • かんきせん（旧軍施設・ダクト内）

手順

  1. 「でんきゅう」＋「でんち」で「かいちゅうでんとう」を合成する。
  2. 「かいちゅうでんとう」を使い、軍艦地下2階の「火気厳禁」の扉を通って奥へ進む。
  3. ボートに「ドラムかん」「かんきせん」をそれぞれ設置する。
  4. 「脱出する」を選ぶとエンディング2。

エンディング3：島で生き抜く

旧軍施設以外の場所で、生存日数が100日に到達するとエンディング3になります。

エンディング4：BB団の仲間になる

旧軍施設の中で、生存日数が100日に到達するとエンディング4になります。

エンディング5：軍艦で脱出

必要アイテム

  • でんきゅう（灯台・地下1階）
  • でんち（旧軍施設・地下1階のゴミ箱「めざましどけい」を分解）
  • かやく（旧軍施設・地下2階）
  • ほうだん（軍艦内部・地下2階）
  • ドラムかん ×3（旧軍施設・地下1階に2個、地下2階に2個、軍艦・地下3階に1個）
  • てつのいた ×2（リモ島「ちょうぼうやま」南東、イシモ島「ひがしの　ジャングル」北東）
  • ボルト ×4（灯台・地下1階、リモ島「てんたきがわ」南東、軍艦内部1階、旧軍施設3階・地下2階・地下1階 などから4つ確保）

※軍艦の階層表記は、甲板を「1階」とした場合です。

手順

  1. 「でんきゅう」＋「でんち」で「かいちゅうでんとう」を合成する。
  2. 「かいちゅうでんとう」を使い、軍艦地下2階右側の「火気厳禁」の扉を通って地下3階へ進む。
  3. 地下3階で「ドラムかん」3個を使い、燃料を補充する。
  4. 地下2階左側の下り階段から地下3階へ行き、軍艦の穴をふさぐ。（「てつのいた」2個と「ボルト」4個が必要）
  5. 「ほうだん」＋「かやく」で「12センチほうだん」を合成する。
  6. まだの場合、軍艦地下2階左側のスイッチで錨を上げておく。
  7. 軍艦内部2階の大砲に「12センチほうだん」を装填し、雨が降って船が大きく揺れているタイミングで近くのボタンを押す。条件を満たしていればエンディング5へ。

※失敗すると「12センチほうだん」は失われ、エンディング5に入れなくなります。事前にセーブしておくのがおすすめです。

条件のまとめ

  • 軍艦の穴をふさいでいる
  • 燃料を補充している
  • 錨を上げている
  • 雨が降り、船がぐらついている
  • その状態で砲弾を発射する

大砲の向きは関係なく、3方向すべてでエンディング入りを確認。

エンディングS：お宝を見つける

必須アイテム

特になし。ただし、戦闘用・探索用の装備がないと非常に厳しいです。

あると楽なアイテム

  • ゆみ（「しなるき」＋「つた」で合成）
  • や（「きのぼう」＋「とりのはね」＋「とがったいし」で合成）
  • ひつけどうぐ（「きのぼう」＋「きのかわ」で合成）

手順

  1. イシモ島南側にある、「夜の間だけ」出入りできる洞窟へ入る。
  2. 奥の部屋で4方向への通路があるフロアに到達したら、右 → 下 → 左 の順でスイッチを押す。上の部屋に下り階段が出現する。
  3. 階段先の部屋左上にあるダイヤモンドを調べて回収する。（通常アイテムとは別枠で、所持アイテム欄には表示されない）
  4. ダイヤモンド入手後、任意のエンディングを達成すると「Sクリア」扱いになる。

攻略メモ

  • 弓矢＋ひつけどうぐがほぼ必須。
  • 洞窟内にはクマが出現し、無限湧きのため、必要な分だけ倒しながら進むイメージ。
  • クマは弓矢約20発ほどで撃破可能。隣接されそうなら、ひつけどうぐで火をつけて距離を取る。矢は壁越しでも当たるため、障害物を挟んで戦うと安全。
  • クマの攻撃はダメージ30以上と危険なので、「隣接させない」ことが最優先。
  • 満腹度・元気・ライフは、クマを倒して作る「やきにく」で回復可能。水分は洞窟内の水場で補給できる。
  • 洞窟は往復が必要で、中にはセーブポイントがない。焦らず慎重に進めるのがおすすめ。

全エンディング達成後（2周目について）

全エンディングを達成すると、スタッフロール後に「2周目に入るかどうか」の選択肢が出ます。

  • 2周目に入るとタイトル画面が少し変化する。
  • 代わりに、1周目のセーブデータは消去される。
